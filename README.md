# Liar System

Liar System è un Social Deduction Experience Engine di Black Bulls Lab. Orchestrerà esperienze sociali live con ruoli segreti, informazioni frammentate, missioni, indizi, BBL Coin, aste, votazioni, reveal e strumenti Regia.

## Primo format

**A Cena Con Il Bugiardo V1**: 30 partecipanti, 5 tavoli da 6, 1 MC/Regia, circa 120 minuti, esperienza prevalentemente offline e meno di 10 minuti medi di telefono per partecipante.

## Stato progetto

Milestone 0 completata: fondazione prodotto, dominio, architettura, sicurezza, database, Realtime, UX e strategia test documentate. Nessuna applicazione è stata implementata.
